## 🚀 Como subir no Cloudflare Pages

1. No painel da **Cloudflare**, vá em **Workers & Pages** > **Pages** > **Connect to Git**.
2. Selecione o repositório do **GitHub**.
3. Na tela de configuração de build (**Set up builds and deployments**):
   - **Framework preset**: `None`
   - **Build command**: *(deixe em branco)*
   - **Build output directory**: *(deixe em branco ou coloque `/`)*
4. Clique em **Save and Deploy**.

A página será publicada instantaneamente com CDN global, SSL automático e carregamento ultra-rápido.
